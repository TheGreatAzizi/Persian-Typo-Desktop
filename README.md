# Persian Typo Fixer Desktop

نسخه دسکتاپ پلاگین مرورری `Persian Typo Fixer` که متن فارسی را در **كل محیط ویندوز و لینوکس** (هر برنامه‌ای که متن انتخاب شده داشته باشد) اصلاح می‌کند.

## کارکرد
- زière سراسری (پیش‌فرض `Ctrl+Shift+F`) → متن انتخاب شده در هر پنجره دریافت می‌شود، اصلاح می‌شود و جای خود می‌گذارد.
- تای سیستمی + پنجره تنظیمات برای روشن/خاموش کردن اصلاحات و دیکشنری شخصی.
- بدون اینترنت؛ همه چیز لوکال اجرا می‌شود.

## ساخت برای ویندوز (.exe)

```powershell
# در پوشه پروژه
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --noconfirm --clean build_windows.spec
```

خروجی در پوشه `dist/Persian Typo Fixer.exe` است.

## ساخت برای لینوکس (آرچ / AppImage)

```bash
chmod +x build_appimage.sh
./build_appimage.sh
```

خروجی AppImage در پوشه `dist/`.

## استفاده
1. برنامه را اجرا کنید (آیکون تای سیستمی نمایش داده می‌شود).
2. در هر برنامه‌ای (ವ στους، تلگرام، ورد، ...) یک متن فارسی را انتخاب کنید.
3. `Ctrl+Shift+F` بزنید — متن اصلاح‌شده جای خود قرار می‌گیرد.
4. برای تنظیمات، دو بار کلیک روی آیکون تای یا منوی تای → تنظیمات.
