# Persian Typo Fixer Desktop

نسخه دسکتاپ افزونه مرورگر `Persian Typo Fixer` که متن فارسی را در **کل محیط ویندوز و لینوکس** اصلاح می‌کند — در هر برنامه‌ای (مرورگر، ورد، تلگرام، ویرایشگر کد و…).

## کارکرد

دو حالت دارد:

**۱) اصلاح خودکار هنگام تایپ (پیش‌فرض روشن)** — همان موقع تایپ، بعد از هر فاصله یا علامت نگارشی، دو کلمهٔ آخر اصلاح می‌شوند (نیم‌فاصله، حروف عربی، غلط‌های رایج، ترکیب‌ها، علائم). نیازی به انتخاب متن یا میانبر نیست. از منوی سینی یا تنظیمات قابل خاموش‌کردن است.

**۲) اصلاح دستی با میانبر** — متنی را انتخاب کنید و `Ctrl+Shift+F` بزنید؛ برنامه متن را می‌خواند، با همان منطق افزونه اصلاح می‌کند و همان‌جا جای متن قبلی می‌گذارد.

امکانات: آیکون در سینی سیستم، روشن/خاموش سریع، پنجره تنظیمات (۱۹ حالت جدا)، دیکشنری شخصی، تغییر میانبر — همه لوکال و بدون اینترنت.

## ساخت برای ویندوز (exe)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --noconfirm --clean build_windows.spec
```

خروجی: `dist/Persian Typo Fixer.exe`

## ساخت برای لینوکس (AppImage برای آرچ و دیگر توزیع‌ها)

```bash
chmod +x build_appimage.sh
./build_appimage.sh
```

خروجی: `dist/Persian Typo Fixer-*.AppImage`

پیش‌نیازهای لینوکس برای کار کردن کلیپ‌بورد و میانبر:
`xclip` (یا `xsel`) برای کلیپ‌بورد X11 و `python-xlib` که خودکار با pyautogui نصب می‌شود. روی Wayland نصب `wl-clipboard` و `ydotool` کمک می‌کند (پشتیبانی Wayland محدود است).

## استفاده

1. برنامه را اجرا کنید؛ آیکون در سینی سیستم ظاهر می‌شود.
2. کافی است عادی تایپ کنید؛ حالت خودکار بعد از فاصله/علامت، کلمات را اصلاح می‌کند.
3. برای اصلاح متن موجود: انتخاب کنید و `Ctrl+Shift+F` بزنید.
4. برای تنظیمات، روی آیکون دوبار کلیک کنید یا از منوی سینی «تنظیمات…» را انتخاب کنید.

نکته‌های سازگاری: اگر برنامهٔ مقصد (مثل تلگرام) با دسترسی Administrator اجرا شده باشد، این برنامه را هم Administrator اجرا کنید. در ترمینال‌ها که `Ctrl+C` معنی دیگری دارد از حالت خودکار استفاده کنید. در Wayland لینوکس پشتیبانی محدود است.
